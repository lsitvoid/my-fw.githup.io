你好，世界

1972 年，Brian Kernighan 在 B 语言教程里写下第一句 hello, world。此后它成了每个程序员与新语言见面的握手礼—— 能不能用最短的代码，向这个世界说出第一句话。

Python

人生苦短

print("Hello, World!")

C

一切从这里开始（1978）

#include <stdio.h>
int main(void) {
    printf("Hello, World!\n");
    return 0;
}

C++

比 C 多一点仪式感

#include <iostream>
int main() {
    std::cout << "Hello, World!" << std::endl;
}

Rust

编译器教做人，然后真香

    println!("Hello, World!");
}

    fmt.Println("Hello, World!")

JavaScript

Assembly（x86-64 Linux NASM）

离系统最近的一声问好

section .data
    msg db "Hello, World!", 10
    len equ $ - msg
section .text
global _start
_start:
    mov rax, 1          ; sys_write
    mov rdi, 1          ; stdout
    mov rsi, msg
    mov rdx, len
    syscall
    mov rax, 60         ; sys_exit
    xor rdi, rdi
    syscall
